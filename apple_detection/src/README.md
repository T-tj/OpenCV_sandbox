# 🍎 苹果目标检测实验：传统视觉 vs 深度学习 (YOLOv8)

## 📖 项目简介
本项目记录了从传统计算机视觉（OpenCV）向深度学习（YOLOv8）演进的全过程。通过多张不同光照、遮挡背景下的苹果图片进行测试，直观对比了传统算法在自然场景下的局限性，以及轻量级深度学习模型的实际表现。

## 📁 文件结构
本项目保留了算法演进的各个版本，便于对比学习：
```text
apple_detection/
├── src/
│   ├── detector.py        # 版本1：传统 OpenCV（基础 HSV 提取 + 外接圆）
│   ├── detector_02.py     # 版本2：传统 OpenCV（加入形态学 + 圆度/半径几何过滤）
│   └── detector_yolo_03.py# 版本3：YOLOv8 深度学习推理
├── data/                  # 测试原图（白底图、自然树叶图等）
├── output/                # 检测结果输出目录
└── README.md
```

🧠 核心踩坑记录与算法对比

1. 传统视觉（Traditional CV）的“调参地狱”

在编写 detector.py 和 detector_02.py 时，遇到了极其致命的泛化问题：

· 高光反光：苹果表面的高光导致 HSV 掩膜断裂，出现黑洞。使用形态学闭运算填补后，若 Kernel 过大，又会导致相邻苹果粘连。
· 遮挡与背景：树叶遮挡导致轮廓不再是一个完美的圆；背景中的暗褐色树干在 HSV 空间中极易与红苹果混淆。
· 几何过滤失效：为了过滤树干，引入了“宽高比”和“填充率”过滤；为了过滤高光，加入了“半径”和“圆度”过滤。但在不同图片中，一旦苹果被遮挡或粘连，这些固定参数不仅没用，反而会误杀真实目标。
· 结论：传统视觉完全依赖手动调参（面积阈值 x、HSV范围等），换一张图就需要重调一套参数，鲁棒性极差。

2. 深度学习（YOLOv8）的降维打击

在 detector_yolo_03.py 中引入了 YOLOv8，彻底抛弃了传统的 HSV 阈值和形态学调参：

· 优势：算法具有语义级理解能力，完美无视高光、树叶遮挡和背景颜色干扰，一套代码通杀所有图片。
· 劣势（轻量级模型痛点）：我们使用的是官方最轻量的模型 yolov8n.pt。轻量模型的特征提取能力有限，导致对远处的极小目标（如远处的模糊苹果）检测效果极差，容易漏检或误判（如把橙黄色苹果识别为 orange）。

🚀 YOLO 远距离小目标的极限调优

针对轻量级模型对远处小目标不友好的问题，经过反复测试，得出以下工业级优化手段：

1. 暴力提升分辨率：将推理时的输入尺寸从默认的 640 修改为 imgsz=2560。这能让远处目标的像素被更大程度保留，显著提升小目标召回率（代价是算力消耗增大，帧率下降）。
2. 降低置信度阈值：将置信度阈值从常规的 0.5 降到 conf=0.15。允许模型“大胆猜测”，把远处哪怕只有 15% 把握的目标也框出来（代价是可能会增加少许误检，但在视觉自瞄中，漏检比误检更致命）。

调优后效果：在远距离、大场景的复杂图片中，该配置成功框出了原本漏检的远景苹果，大幅提升了检测数量与真实数量的一致性。
